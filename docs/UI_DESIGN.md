# طراحی بصری و تجربه کاربری «خمس‌یار»

> این سند معادل متنی طراحی فیگما است و مشخصات دقیق رنگ، تایپوگرافی،
> فاصله‌ها، انیمیشن و چیدمان هر صفحه را تعریف می‌کند.

## ۱. زبان طراحی

- **سبک:** مدرن، مینیمال، اسلامی
- **حس کلی:** آرامش، تعالی، اعتماد
- **جهت:** راست‌چین (RTL) کامل برای فارسی/عربی؛ LTR برای انگلیسی
- **اصول:** فضای سفید فراوان، گوشه‌های نرم (radius ۱۶–۲۰)، سایه‌های ملایم،
  الگوهای هندسی محو در پس‌زمینه

## ۳. تایپوگرافی

- **فونت:** وزیرمتن (Vazirmatn) — جایگزین: ایران‌سنس
- **وزن‌ها:** Regular 400، Medium 500، Bold 700

| سبک | اندازه | وزن | line-height |
|------|--------|-----|-------------|
| نمایش بزرگ (عدد خمس) | 40 | 700 | 1.4 |
| عنوان بخش | 20 | 700 | 1.5 |
| عنوان کارت | 17 | 600 | 1.6 |
| متن اصلی | 16 | 400 | 1.8 |
| متن فرعی | 14 | 400 | 1.7 |
| برچسب | 14 | 600 | 1.5 |

## ۴. آیکون‌گرافی

- آیکون‌های مینیمال خطی
- المان‌های اسلامی: 🕌 گنبد (mosque)، ☪️ هلال، ✨ ستاره هشت‌پر
- **نشان اپ (Emblem):** گنبد سبز + پایه طلایی + هلال — با `CustomPainter`
  پیاده‌سازی شده (`IslamicEmblem`)
- **الگوی پس‌زمینه:** ستاره هشت‌پر تکرارشونده با شفافیت ۶٪ طلایی —
  پیاده‌سازی‌شده در `IslamicPatternBackground`

## ۵. انیمیشن

| مورد | مشخصات |
|------|---------|
| انتقال بین صفحات | 300ms، easeInOut |
| ورود کارت‌ها | Fade + Slide-up، 350ms، stagger 50ms |
| شمارش اعداد (نتیجه) | Tween 800ms، easeOut |
| لمس دکمه | Ripple ملایم + Scale 0.98، 100ms |
| تغییر تم | 250ms crossfade |
| چرخش ستاره هنگام بارگذاری | 1200ms loop، linear |

## ۶. ساختار شبکه و فاصله‌ها

- حاشیه صفحه: ۱۶
- فاصله بین کارت‌ها: ۸–۱۲
- padding داخلی کارت: ۱۶
- radius کارت: ۲۰ | radius دکمه/فیلد: ۱۴–۱۶
- حداقل ارتفاع دکمه اصلی: ۵۴

## ۷. صفحات

### 7.1 خوش‌آمد / انتخاب مرجع (Onboarding)
- نشان اپ در بالای صفحه (۸۰×۸۰)
- عنوان «مرجع تقلید خود را انتخاب کنید» + زیرعنوان
- لیست کارت‌های مراجع: آواتار گنبد + نام + خلاصه قاعده
- کارت انتخاب‌شده: حاشیه طلایی ۲px + پس‌زمینه سبز ۸٪ + تیک سبز
- دکمه «افزودن سایر مراجع» (outline سبز)
- دکمه اصلی «بعدی/ذخیره» + جعبه سلب مسئولیت طلایی

### 7.2 صفحه اصلی (Home)
- هدر سبز با عنوان «خمس‌یار» + آیکون تنظیمات
- کارت «مرجع تقلید شما»
- **کارت وضعیت سال خمسی** (نمایان‌گر ویجت صفحه اصلی): پس‌زمینه سبز زمردی،
  آیکون تقویم طلایی، عدد بزرگ روزهای باقی‌مانده + برچسب
- چهار کارت دسترسی سریع: محاسبه، سال خمسی، پرداخت، مشاوره
- جعبه سلب مسئولیت در پایین

### 7.3 فرم محاسبه
- کارت‌های بخش‌بندی‌شده با آیکون و عنوان:
  - درآمد سالانه (سرمایه)
  - مخارج سالانه (رسید) — ۸ فیلد تفکیک‌شده
  - سرمایه و اموال (الماس) — ۸ فیلد
  - اموال معاف (تیک امنیت) — ۴ فیلد
- فیلدهای مبلغ: جداکننده هزارگان زنده، پسوند «تومان»، آیکون رشته‌ای
- **راهنمای پویا:** اگر مرجع هزینه‌ای را کسر نمی‌کند، زیر فیلد یادداشت
  نمایش می‌یابد (مثلاً «طبق نظر این مرجع کسر نمی‌شود»)
- سوییچ «محاسبه فقط بر مازاد درآمد»
- دکمه اصلی «محاسبه خمس»

### 7.4 نتیجه محاسبه
- کارت سبز بالای صفحه: برچسب «خمس واجب» + عدد بزرگ طلایی
- تفکیک سهم امام و سهم سادات در دو ستون با جداکننده
- کارت «جزئیات محاسبه»: درآمد، مخارج، دارایی مشمول، پس‌انداز معاف،
  اموال معاف، مازاد، نرخ — با رنگ تأکیدی روی مازاد
- کارت «تفکیک مخارج»
- کارت هشدارهای شرعی (نارنجی)
- کارت یادداشت‌های فقهی (سبز)
- دکمه «پرداخت»

### 7.5 سال خمسی
- کارت «راهنمای تعیین مبدأ» با ۴ آیتم (حقوق، متغیر، کشاورزی، تجارت)
- کارت انتخاب تاریخ مبدأ (DatePicker)
- کارت شمارش معکوس سبز
- کارت یادآور با دو سوییچ (۳۰ روز / ۷ روز)
- دکمه «فعال‌سازی یادآور»

### 7.6 پرداخت
- کارت سبز مبلغ قابل پرداخت
- کارت انتخاب سهم: سهم امام / سهم سادات / هر دو (Radio)
- کارت انتخاب درگاه: زرین‌پال / آیدی‌پی / سامان (Radio با لوگو)
- جعبه یادداشت فقهی مرجع
- دکمه پرداخت با حالت Loading
- **گارد شرعی:** اگر سهم امام نیاز به اجازه دارد، دیالوگ تأیید نمایش داده می‌شود

### 7.7 تاریخچه پرداخت
- لیست کارت‌ها: نوع سهم + درگاه + تاریخ | مبلغ | آیکون وضعیت
- وضعیت با رنگ: موفق (سبز)، در انتظار (نارنجی)، ناموفق (قرمز)
- حالت خالی: آیکون بزرگ + پیام «پرداختی ثبت نشده است»

### 7.8 مشاوره
- سه تب: چت / تماس / سوالات
- **چت:** حباب پیام کاربر (سبز) و مشاور (طلایی محو)، فیلد ورودی + دکمه ارسال
- **تماس:** کارت دفتر مرکزی + لیست دفاتر شهرها + وب‌سایت
- **سوالات:** کارت‌های ExpansionTile برای FAQ هر مرجع

### 7.9 تنظیمات
- کارت مرجع (تغییر)
- کارت زبان: فارسی / العربية / English
- کارت ظاهر: سوییچ حالت تاریک
- کارت تنظیم دستی قواعد
- کارت حریم خصوصی
- کارت درباره

## ۸. دسترس‌پذیری

- کنتراست رنگ حداقل ۴.۵:۱
- پشتیبانی از font scaling
- برچسب معنایی برای صفحه‌خوان‌ها
- حالت تاریک کامل برای همه صفحات
- همه اعداد با `NumberFormat` و جداکننده هزارگان
