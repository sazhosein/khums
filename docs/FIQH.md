# مستندات فقهی «خمس‌یار»

> ⚠️ **هشدار مهم**
>
> این سند و قواعد مندرج در آن، **جنبه کمک‌آموزشی** دارند و بر پایه منابع عمومی
> (رساله‌های عملیه و استفتائات منتشرشده) تنظیم شده‌اند. این اپلیکیشن
> **صادرکننده حکم شرعی نیست**. پیش از انتشار نهایی، تمام قواعد باید توسط
> **دفاتر مراجع محترم** بازبینی و تأیید شوند (فیلد `verified_by_office` در
> دیتابیس برای همین منظور است).
>
> در موارد اختلافی، کاربر باید بتواند قواعد را **دستی تنظیم** کند.

---

## ۱. مفهوم خمس

خمس، یک‌پنجم (۲۰٪) مال مازاد بر مؤونه (مخارج سالانه) است که بر اساس آیه ۴۱
سوره انفال و روایات، در هفت مورد واجب می‌شود:

1. منفعت کسب (مهم‌ترین مورد در زندگی امروزی)
2. معدن
3. گنج
4. مال حلال مخلوط به حرام
5. جواهری که با غواصی به دست می‌آید
6. غنیمت جنگی
7. آنچه از کافر ذمی خریداری شده (در برخی نظرات)

## ۲. فرمول کلی محاسبه

```
مازاد بر مؤونه = کل درآمد سال
              − مخارج متعارف سال (مؤونه)
              + دارایی‌های مشمول خمس
              − پس‌انداز معاف (بسته به نظر مرجع)
              − اموال معاف (ارث، مهریه، دیه)

خمس       = مازاد بر مؤونه × ۲۰٪
سهم امام   = خمس × ۵۰٪
سهم سادات  = خمس × ۵۰٪
```

## ۳. مؤونه (مخارج قابل کسر)

| مورد | وضعیت کلی |
|------|-----------|
| خوراک، پوشاک، مسکن | قابل کسر (متعارف) |
| درمان | قابل کسر |
| آموزش | قابل کسر |
| بدهی‌ها | قابل کسر در سالی که پرداخت شده |
| اسراف و مخارج غیرمتعارف | قابل کسر نیست |

> اگر درآمد سالی کمتر از مخارج بود، مابه‌التفاوت از درآمد سال‌های آینده کسر
> می‌شود (به «مؤونه استمراری» مراجعه کنید).

## ۴. اموال معاف

- **ارث:** معاف است (اگر عین مال باقی بماند).
- **مهریه:** معاف است.
- **دیه:** معاف است.
- **هبه و هدیه:** در برخی نظرات معاف (قابل تنظیم).

## ۵. قواعد اختصاصی مراجع (پیش‌فرض فعلی)

### آیت‌الله خامنه‌ای (`khamenei`)
- **پرداخت:** باید به دفتر مرجع یا وکیل ایشان پرداخت شود.
- **پس‌انداز:** پس‌انداز برای پیشامدها (با شرایط) معاف است.
- **سهم سادات:** پرداخت مستقیم نیاز به اذن دارد.

### آیت‌الله سیستانی (`sistani`)
- **سهم سادات:** به‌طور مستقیم قابل پرداخت است.
- **سهم امام:** نیاز به اجازه از دفتر ایشان دارد.

### آیت‌الله مکارم شیرازی (`makarem`)
- **جهیزیه:** در شهرهای متعارف، تهیه تدریجی معاف است.

### آیت‌الله شبیری زنجانی (`shobeiri`)
- **پس‌انداز:** پس‌انداز برای هزینه‌های ضروری آینده معاف است.

### آیت‌الله نوری همدانی (`noori`)
- برای پرداخت، مشورت با دفتر مرجع توصیه می‌شود.

### سرمایه و اموال تجاری (نظر مشترک بیشتر مراجع)
- اگر کالا/سرمایه **از درآمد سال** خریداری شده و **خمس آن پرداخت نشده**،
  مشمول خمس است.

## ۶. تعیین سال خمسی

| نوع درآمد | مبدأ سال خمسی |
|-----------|----------------|
| حقوق ثابت | اولین روز دریافت حقوق |
| درآمد متغیر/آزاد | روز اول کسب اولین درآمد از این نوع |
| کشاورزی | زمان برداشت محصول |
| تجارت | روز گردش سرمایه / اولین فروش |

> اگر تاکنون سال خمسی مشخص نکرده‌اید، برای اولین سال می‌توانید با مرجع
> خود مشورت کنید.

## ۷. ساختار داده قواعددر اپ

هر مرجع یک شیء `rules` دارد با فیلدهای زیر:

| فیلد | نوع | توضیح |
|------|-----|-------|
| `paymentPolicy` | enum | `toMarjaOffice` / `sayyidDirectImamPermission` / `freePayment` |
| `emergencySavingsExempt` | bool | پس‌انداز پیشامدها معاف؟ |
| `futureNecessitiesSavingsExempt` | bool | پس‌انداز ضروری آینده معاف؟ |
| `trousseauExempt` | bool | جهیزیه معاف؟ |
| `gradualTrousseauExempt` | bool | تهیه تدریجی جهیزیه معاف؟ |
| `sayyidShareDirectPayment` | bool | سهم سادات مستقیم پرداخت شود؟ |
| `imamShareRequiresPermission` | bool | سهم امام نیاز به اجازه؟ |
| `capitalBoughtFromUnkhumsedIncome` | bool | سرمایه از درآمد سال مشمول؟ |
| `medicalExpensesDeductible` | bool | درمان از مؤونه کسر شود؟ |
| `debtsDeductible` | bool | بدهی‌ها کسر شود؟ |
| `inheritanceExempt` / `dowryExempt` / `bloodMoneyExempt` | bool | معافیت اموال |
| `khumsRate` | double | نرخ خمس (پیش‌فرض ۰.۲) |
| `imamShareRatio` / `sayyidShareRatio` | double | نسبت سهم‌ها (۰.۵ / ۰.۵) |

## ۸. فرآیند تأیید پیش از انتشار

1. استخراج قواعد از رساله و استفتائات هر مرجع.
2. مکاتبه با دفتر مرجع و ارسال جدول قواعد.
3. اعمال اصلاحات در seed بک‌اند.
4. درج در دیتابیس با `verified_by_office = true` و `approved_at`.
5. انتشار نسخه اپ و اطلاع‌رسانی نسخه قواعد از طریق `GET /v1/marjas/meta/version`.

## ۹. منابع پیشنهادی

- رساله‌های توضیح‌المسائل مراجع (بخش خمس).
- استفتائات منتشرشده در سایت‌های رسمی دفاتر.
- سایت رسمی هر مرجع (به فیلد `websiteUrl` در داده‌های هر مرجع مراجعه کنید).
