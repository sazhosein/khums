## ⚠️ سلب مسئولیت شرعی

این اپلیکیشن **فقط ابزار محاسبه** است و **صادرکننده حکم شرعی نیست**.
نتیجه محاسبه جنبه کمک‌آموزشی دارد. برای اطمینان، با دفتر مرجع خود مشورت کنید.
قواعد فقهی هر مرجع پیش از انتشار نهایی باید توسط **دفتر آن مرجع تأیید** شود.

## 🏗️ معماری

```
khums/
├── flutter_app/            # اپلیکیشن Flutter (iOS/Android)
│   └── lib/
│       ├── models/         # Marja, KhumsInput, KhumsResult
│       ├── services/       # محاسبه، پرداخت، اعلان، API
│       ├── data/           # مخزن مراجع و قواعد
│       ├── pages/          # صفحات UI
│       ├── widgets/        # ویجت‌های مشترک و الگوهای اسلامی
│       ├── state/          # Riverpod providers
│       ├── theme/          # پالت و تم
│       └── l10n/           # چندزبانه‌سازی
│
├── backend/                # سرور Node.js + PostgreSQL
│   └── src/
│       ├── routes/         # marjas, auth(OTP), faqs, payments
│       ├── services/       # درگاه‌ها، پیامک
│       ├── middleware/     # احراز هویت JWT
│       └── db/             # knex، migrations، seeds
│
└── docs/                   # مستندات فقهی، UI، راه‌اندازی
```

**پشته فناوری:**
- **اپ:** Flutter 3.3+ / Riverpod / Dio / Hive + Secure Storage
- **بک‌اند:** Node.js 20+ / Express / Knex / PostgreSQL 15+
- **احراز هویت:** OTP پیامکی + JWT

## 🚀 راه‌اندازی سریع

راهنمای کامل در [docs/SETUP.md](docs/SETUP.md). خلاصه:

### اپ Flutter
```bash
cd flutter_app
flutter pub get
flutter run
```

### بک‌اند
```bash
cd backend
cp .env.example .env      # و مقادیر را تنظیم کنید
npm install
npm run migrate
npm run seed
npm run dev
```

سرویس روی `http://localhost:3000` بالا می‌آید. تست سلامت:
`GET /health`
